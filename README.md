# GitHub Final Project

## Simple Interest Calculator

This project contains a Bash script to calculate simple interest using the principal amount, rate of interest, and time period.

### Formula

Simple Interest = (Principal × Rate × Time) / 100

### Inputs

- **Principal:** The initial amount of money.
- **Rate:** The annual rate of interest in percentage.
- **Time:** The time period in years.

### Example

Principal = 1000

Rate of Interest = 5%

Time = 2 years

Calculation:

Simple Interest = (1000 × 5 × 2) / 100 = 100

Output: 100

### How to Run

Run the script from a terminal:

```bash
bash simple-interest.sh
```
