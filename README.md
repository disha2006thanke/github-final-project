# GitHub Final Project

## Simple Interest Calculator

This project calculates simple interest using the principal amount, rate of interest, and time period.

### Formula

Simple Interest = (Principal × Rate × Time) / 100

### Inputs

- Principal: Initial amount of money
- Rate: Annual rate of interest in percentage
- Time: Time period in years

### Example

Principal = 1000  
Rate = 5  
Time = 2 years

Simple Interest = (1000 × 5 × 2) / 100 = 100

### How to Run

Run the Bash script:

```bash
bash simple-interest.sh
```
